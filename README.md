# Wasteefy

Wasteefy is an innovative application designed to simplify waste management payments and allocations for both customers and PSP (Private Sector Participation) operators. The app provides an easy-to-use platform for streamlined transactions and effective waste collection organization.

## Features

- **Easy Payment System**: Enables seamless payments for waste management services based on apartment and property details.
- **Efficient Allocation**: Automatically assigns PSP operators for optimized waste collection and resource management.
- **User-Friendly Interface**: Designed for hassle-free navigation for both customers and operators.
- **Transparency and Accountability**: Ensures clear communication and reliable service records between customers and PSPs.
- **Resource Optimization**: Helps operators manage resources effectively by integrating property-based allocation.
